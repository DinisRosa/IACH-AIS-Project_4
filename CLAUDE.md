# Instruções do projeto AIS

Antes de qualquer ação, ler integralmente AGENTS.md na raiz do projeto e seguir as suas regras. Esse ficheiro é a fonte única das instruções do projeto. Se não for carregado automaticamente, abri-lo explicitamente antes de editar ou executar comandos.

Restrições essenciais: desenvolvimento só no treino ou dados sintéticos; não abrir validação/teste sem autorização; git push só quando o utilizador o pede explicitamente (nunca por iniciativa própria) e nenhuma outra publicação remota; explicar comandos e alterações. Não tratar esta ponte como substituto da leitura completa.
